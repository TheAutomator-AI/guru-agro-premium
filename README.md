# 🌾 Guru Agro Premium

A premium website redesign concept for an agricultural products brand.

The project focuses on turning a conventional product website into a more modern digital experience with stronger visual hierarchy, product storytelling and responsive presentation.

## ✨ Focus

- Premium brand presentation
- Product-first storytelling
- Responsive layouts
- Modern UI interactions
- Clear calls to action
- Mobile-friendly experience

## 🛠️ Stack

- React
- TypeScript
- Vite
